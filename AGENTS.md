# Yonxiek Bot

Проектные инструкции для ассистента.

## Язык
- Общение с пользователем и все тексты в коде (эмбеды, сообщения) — на русском.

## Стек
- Python 3.14, discord.py. Слэш-команды через `@app_commands.command`.
- Префиксные команды НЕ дублируют логику слэшей: они вызывают те же методы через `prefix_adapter.InteractionAdapter` (DRY). Новые команды добавляются по этой же схеме.

## Команды
- Добавлять только НУЖНЫЕ команды; не плодить мелкие функции как отдельные топ-команды.
- Всё, что настраивается (каналы, роли, параметры, запуск событий) — в `/setup`.
- Личные действия (установить/удалить/посмотреть своё) — кнопками и модалками в `/menu`.
- Экономические механики (покупки, лотереи, кейсы) — в `/shop`.
- Убирать top-level команду, если она переезжает в `/setup`, `/menu` или `/shop`.

## Git-процесс (важно)
- Коммитить и пушить без запроса подтверждения у пользователя.
- Перед коммитом: `git status`, `git diff`, `git log --oneline -10` — убедиться, что стейджится только нужное, без секретов и `.env`.
- Сообщения коммитов — краткие, по-русски, в стиле существующих.
- Не пушить, если push требует интерактивного ввода пароля — сообщить пользователю, что нужен `gh auth login` / credential helper.

## Проверка кода
- Если есть тесты — запустить. По умолчанию хотя бы синтаксис:
  `python -m py_compile <изменённые файлы>` (пути содержат пробел — кавычки!)
