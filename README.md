## 🚀 Установка и запуск

### 1. Клонирование
```bash
git clone <URL-репозитория>
cd <папка-проекта>
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\Scripts\activate        # Windows

pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте пример конфигурации и заполните свои значения:
```bash
cp .env.example .env
```
Откройте `.env` и укажите как минимум:
```
TOKEN=ваш_токен_бота
```

| Переменная | Описание | Обязательно |
|------------|----------|:-----------:|
| `TOKEN` | Токен Discord-бота | ✅ |
| `PREFIX` | Префикс текстовых команд (по умолчанию `,`) | ❌ |
| `DB_URL` | Путь к SQLite-базе (по умолчанию `data/bot.db`) | ❌ |
| `ERROR_WEBHOOK_URL` | Вебхук для отправки ошибок | ❌ |
| `BLOXLINK_API_KEY` | API-ключ Bloxlink (Discord → Roblox) | ❌ |
| `SNIPE_WEBHOOK_URL` | Вебхук для событий | ❌ |

> ⚠️ **Никогда не коммитьте файл `.env`** — он содержит секреты и уже исключён через `.gitignore`.

### 4. Запуск
```bash
python main.py
```
После запуска бот автоматически синхронизирует слэш-команды.

## 🤖 Создание бота на Discord Developer Portal

1. Зайдите на [Discord Developer Portal](https://discord.com/developers/applications) и создайте приложение.
2. Во вкладке **Bot** нажмите **Add Bot** и скопируйте **Token**.
3. Включите необходимые **Intents** (Members, Message Content, Presence).
4. Вставьте токен в `.env`.
5. Пригласите бота с нужными разрешениями через **OAuth2 → URL Generator**.

## 📂 Структура проекта

```
├── main.py               # Точка входа, запуск бота, загрузка когов
├── config.py             # Конфигурация из переменных окружения
├── db.py                 # Слой работы с базой данных (SQLite/aiosqlite)
├── ui_components.py      # Иконки, цвета, утилиты
├── cogs/                 # Модули команд (коги)
│   ├── moderation.py     # Модерация и наказания
│   ├── economy.py        # Экономика и профили
│   ├── levels.py         # Уровни и опыт
│   ├── shop.py           # Магазин и титулы
│   ├── quests.py         # Квесты
│   ├── minigames.py      # Мини-игры
│   ├── logging.py        # Логирование событий
│   ├── security.py       # Anti-Nuke защита
│   ├── permissions.py    # Права доступа
│   ├── utils.py          # Утилиты, заявки, вебхуки, Roblox
│   └── ...               # остальные модули
├── data/                 # База данных SQLite (не в git)
├── .env                  # Секреты (не в git)
└── .env.example          # Шаблон конфигурации
```

---

## 🔐 Безопасность

- **Секреты** хранятся только в `.env` и не попадают в git.
- Файл `.env.example` содержит только пустые/заглушечные значения.
- SQLite-база в `data/` исключена из контроля версий.
